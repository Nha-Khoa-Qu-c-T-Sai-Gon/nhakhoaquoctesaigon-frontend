# About Us Page Components

This directory contains sub-components extracted from the `AboutUsContent` view to ensure a modular architecture and clean code structure.

## Components List

### 1. `AboutUsHero`
- **Path**: `src/components/about-us/AboutUsHero.tsx`
- **Purpose**: Displays the top Hero section, introducing the clinic with floating mosaic images.

### 2. `RecognizedExcellence`
- **Path**: `src/components/about-us/RecognizedExcellence.tsx`
- **Purpose**: Renders numerical achievements and clinical statistics dashboard.

### 3. `AboutUsWhyChooseUs`
- **Path**: `src/components/about-us/AboutUsWhyChooseUs.tsx`
- **Purpose**: Lists feature items showcasing modern equipment and high-end services.

### 4. `PhilosophySection`
- **Path**: `src/components/about-us/PhilosophySection.tsx`
- **Purpose**: Renders tabs showing clinical designs and philosophy guides.

### 5. `CoreValuesSection`
- **Path**: `src/components/about-us/CoreValuesSection.tsx`
- **Purpose**: Displays interactive orbits listing clinical standards.

### 6. `CommitmentSection`
- **Path**: `src/components/about-us/CommitmentSection.tsx`
- **Purpose**: Lists patient statistics along with clinical firm guarantees.
