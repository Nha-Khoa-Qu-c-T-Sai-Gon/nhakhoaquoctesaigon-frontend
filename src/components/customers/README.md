# Customer Testimonial Page Components

This directory contains sub-components extracted from the `CustomerContent` view to ensure a modular architecture and clean code structure.

## Components List

### 1. `CustomerHero`
- **Path**: `src/components/customers/CustomerHero.tsx`
- **Purpose**: Displays the top Hero section, introducing the testimonial page with interactive explore buttons and floating images.

### 2. `SuccessStories`
- **Path**: `src/components/customers/SuccessStories.tsx`
- **Purpose**: Displays patient quotes and treatments in a desktop grid or mobile carousel.

### 3. `WhyChooseUs`
- **Path**: `src/components/customers/WhyChooseUs.tsx`
- **Purpose**: Lists clinic benefits with custom graphic checkmark pills.

### 4. `ReviewsSection`
- **Path**: `src/components/customers/ReviewsSection.tsx`
- **Purpose**: Details star ratings and score averages along with patient compliance checklist items.
