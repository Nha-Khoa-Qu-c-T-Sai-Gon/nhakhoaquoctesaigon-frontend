# News Page Components

This directory contains sub-components extracted from the `NewsPageClient` route view to ensure a modular architecture and clean code structure.

## Components List

### 1. `NewsHeroSection`
- **Path**: `src/components/news/NewsHeroSection.tsx`
- **Purpose**: Displays the main top banner of the News page, including title headers, decorative floating images, and the search input bar.

### 2. `CategoryFilter`
- **Path**: `src/components/news/CategoryFilter.tsx`
- **Purpose**: A sticky navigation bar containing category filter tags, utilizing smooth slide transition highlights.

### 3. `FeaturedArticle`
- **Path**: `src/components/news/FeaturedArticle.tsx`
- **Purpose**: Formats the first or top article in an editorial layout with horizontal imagery and description text.

### 4. `BlogCard`
- **Path**: `src/components/news/BlogCard.tsx`
- **Purpose**: Formats regular articles inside the main grid. Contains hover lifts and card layouts.
